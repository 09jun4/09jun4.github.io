# FOLD : 접힌 세계 (FOLD : The Folded World)

종이를 접어 떨어진 공간을 잇는 3D 공간 변형 퍼즐. PC(키보드·마우스)와 모바일(터치) 모두 지원.
주소: https://09jun4.github.io/fold/

## 실행
- 배포: 빌드 없이 파일 그대로 GitHub Pages 에서 실행 (ES 모듈 + `vendor/three.module.min.js` r170).
- 로컬: 저장소 루트에서 `python3 -m http.server` 후 `http://localhost:8000/fold/` (구글 로그인 SDK 를 `/track-master/` 에서 불러오므로 루트에서 띄우기)
  - `npx vite` 로 `fold/` 를 열어도 동작 (이때는 로그인 SDK 가 없어 브라우저 저장만 사용).
  - `?stage=2-3` 으로 특정 스테이지 바로 열기 (잠금 해제된 것 / localhost 는 전부).
- 테스트: `node tests/run.js` — 단위 테스트 + 12개 스테이지 전부 자동 풀이·재생 검증.

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | WASD·방향키, 바닥 클릭 | 바닥 터치 (길찾기 자동 이동) |
| 접기 | 접힘선이나 접히는 종이를 잡고 끌기 (끝까지 끌면 180°) · Tab 선택 후 Q/E | 끌기 · 접힘선 탭 → 화살표 버튼 |
| 밀기 | 블록에 부딪히기 | 블록을 미는 방향으로 쓸기 |
| 거울 | 부딪히기 | 거울 터치 (걸어가서 돌림) |
| 기타 | Z 되돌리기 · R 다시 · H 힌트 · F 전체 화면 · Esc 메뉴 | 화면 위 버튼 |

## 구조 (논리 / 화면 / 충돌 분리)
```
js/logic/      ← Three.js 를 모르는 순수 논리 (Node 에서 테스트)
  math.js         90° 정수 회전 행렬 — 접기 결과가 부동소수 오차 없이 정확한 격자에 놓임
  StageLoader.js  스테이지 JSON 검증·파싱 (틀리면 위치를 알려 주는 오류)
  Layout.js       접힘 각도 → 면 변환, 걸을 칸·벽 (Collision Layer, 캐시)
  Collision.js    이웃 칸 이동 판정, 밀기/거울/문 접촉, 길찾기
  Connection.js   서로 다른 면의 경계 연결 판정 (높이·위치·벽 검사)
  Puzzle.js       스위치·광선 반사·수신기·문·출구 (문↔빛 고정점 계산)
  Fold.js         접기 검증과 적용, 겹침 순서, 물체 끼임 거부, 블록 중력
  Sim.js          논리 상태 중심 (되돌리기·재시작·이벤트)
  Solver.js       너비 우선 자동 풀이 (스테이지 검증 + 힌트)
js/render/     ← Visual Layer
  Renderer.js     렌더러·조명·그림자·품질·고정 아이소메트릭 카메라
  PaperMaterial.js / PaperGeometry.js  섬유 질감 캔버스 텍스처, 구멍까지 반영한 두께 있는 종이 판
  StageView.js    면·접힘선·물체·광선·연결 빛, 접기 미리보기/애니메이션, 가림 반투명
  ObjectViews.js  블록·스위치·문·열쇠·거울·광원·수신기·출구·계단 (직접 만든 메시)
  PlayerView.js   종이 인형 + 절차적 애니메이션
  MenuScene.js / DebugView.js
js/core/       Game(상태 머신·입력), Player(연속 이동+칸 충돌), Hint, Audio(Web Audio 합성), Save, Cloud(Firebase)
js/ui/UI.js    메뉴·스테이지 선택·HUD·일시정지·설정·완료 화면
stages/        index.json + 챕터별 스테이지 JSON
```

## 핵심 규칙
- 면은 접힘선(경첩)으로 부모 면에 붙은 트리. 접힘선을 돌리면 자식 면 전체가 함께 돌아요 (90° 단위, 한 번에 최대 180°).
- 걷기: 위를 향한 수평 면 위만, 같은 높이 이웃 칸으로. 높이는 계단으로만. 수직 면·종이 턱은 벽.
- 연결: 다른 면의 칸이 같은 높이로 맞닿고 경계에 벽이 없으면 연결 (경계가 은은하게 빛남, 새로 생기면 반짝).
- 겹침: 위로 넘어온 종이는 위에, 아래로 돌아온 종이는 아래에. 180° 로 뒤집힌 묶음은 순서가 뒤집힘.
- 물체는 붙은 종이와 함께 움직이고, 위를 향할 때만 작동. 서 있는 물체가 종이에 깔리면 그 접기는 거부.
- 블록은 기울면 아래 바닥으로 떨어지고, 떨어질 곳이 없으면 처음 자리로 돌아가요. 블록끼리는 쌓이지 않아요.
- 접는 동안·접히는 종이 위에 서 있을 때는 접기·이동이 막혀요.

## 스테이지 (2챕터 12개, 모두 자동 풀이로 해결 가능 검증)
| | 이름 | 배우는 것 | 최소 행동 |
|---|---|---|---|
| 1-1 | 첫 접기 | 접기 = 다리 | 1 |
| 1-2 | 이어진 길 | 두 종이 맞대기, 경계 정렬 (다른 해법 있음) | 2 |
| 1-3 | 건너기 | 포개진 종이 180° 펼치기, 서 있는 종이는 못 접음 | 3 |
| 1-4 | 블록 | 밀기, 종이를 세워 블록 던지기 | 3 |
| 1-5 | 스위치 | 종이 턱, 블록으로 스위치 → 문 | 3 |
| 1-6 | 닫힌 공간 | 뚜껑 달린 상자, 2단 접기, 열쇠 문 | 3 |
| 2-1 | 거울 | 광원·거울·수신기, 조건부 다리 | 2 |
| 2-2 | 반사 | 두 번 접어 거울을 한 층 들어 올리기 | 3 |
| 2-3 | 접힌 길 | 계단, 지그재그 3겹 펼치기 | 3 |
| 2-4 | 겹 | 구멍 난 종이 포개기 (무늬 거울 반전) | 2 |
| 2-5 | 공간 논리 | 블록→스위치→문→빛→거울→수신기 | 5 |
| 2-6 | 접힌 세계 | 모든 기믹 (열쇠·계단·승강 접기·스위치·빛) | 9 |

새 스테이지는 JSON 만 추가하면 돼요 (`stages/index.json` 의 챕터 `stages` 에 파일 추가). 형식은 기존 파일 참고:
`faces`(o/u/v/w/h/mask/closed/when), `creases`(parent/child/a/b/min/max), `objects`(type/at 또는 face·i·j·side, dir, mirror, when, key), `player`, `goal.requires`, `intro`, `story`, `hints`.
`node tests/run.js <id>` 로 풀 수 있는지와 최소 해법을 바로 확인할 수 있어요.

## 설정 · 저장
- 설정: 전체/음악/효과음 볼륨, 그래픽 품질(낮음: 그림자 끔·0.75배 해상도·Lambert / 보통: 1024 그림자 / 높음: 2048 부드러운 그림자·2배 해상도·종이 요철), 전체 화면. 바꾸면 바로 저장.
- 진행: 완료한 스테이지·최소 접기 기록, 일시정지 메뉴의 "저장"으로 스테이지 중간 상태 저장 → 메인 메뉴 "이어하기".
- localStorage (쓰기 전 백업 칸 유지, 손상 시 백업 사용, 버전 필드). 구글 로그인하면 Firestore `fold_users/{uid}` 에도 저장 — 게스트 진행은 첫 로그인 때 계정으로 옮기고, 로그아웃하면 게스트로.
- 관리자(사이트 주인 계정, 이메일 SHA-256 으로 판별): 모든 스테이지 열림 + 디버그 화면(` 키 / 일시정지 메뉴).

## 성능
- 접힘 배치 계산 캐시, 지오메트리·텍스처 공유, 연결 빛은 인스턴싱, 그림자 카메라를 무대에 맞춤.
- 가리는 면 반투명 처리는 4프레임마다. 힌트 탐색은 프레임을 12ms 씩 끊어 실행 (최대 4초, 넘으면 글 힌트).

## 테스트 결과
- `node tests/run.js`: 단위 테스트(회전·접기·연결·충돌·되돌리기) + 12개 스테이지 자동 풀이 → 실제 동작으로 재생해 출구 도착까지 통과.
- 브라우저(Chromium, Playwright): 12개 스테이지 모두 실제 게임 조작(걷기·계단·접기·밀기·거울·열쇠)으로 완료 확인, 모바일(iPhone 13 에뮬레이션) 터치 탭·접힘선 선택·화살표 접기·터치 드래그 접기·힌트 확인, 일시정지·저장·이어하기·품질 변경 확인. 콘솔 오류 없음.
