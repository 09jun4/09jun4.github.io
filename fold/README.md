# FOLD : 접힌 세계 (FOLD : The Folded World)

종이를 접어 떨어진 공간을 잇는 3D 공간 변형 퍼즐. PC(키보드·마우스)와 모바일(터치) 모두 지원.
주소: https://09jun4.github.io/fold/

## 실행
- 배포: 빌드 없이 파일 그대로 GitHub Pages 에서 실행 (ES 모듈 + `vendor/three.module.min.js` r170).
- 로컬: 저장소 루트에서 `python3 -m http.server` 후 `http://localhost:8000/fold/` (구글 로그인 SDK 를 `/track-master/` 에서 불러오므로 루트에서 띄우기)
  - `npx vite` 로 `fold/` 를 열어도 동작 (이때는 로그인 SDK 가 없어 브라우저 저장만 사용).
  - `?stage=2-3` 으로 특정 스테이지 바로 열기 (잠금 해제된 것 / localhost 는 전부).
- 테스트: `node tests/run.js` — 단위 테스트 + 12개 스테이지 전부 자동 풀이·재생 검증.

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | WASD·방향키, 바닥 클릭 | 바닥 터치 (길찾기 자동 이동, 착시·숨은 길 포함) |
| 접기 | 접힘선이나 접히는 종이를 잡고 끌기 (끝까지 끌면 180°) · Tab 선택 후 Q/E | 끌기 · 접힘선 탭 → 화살표 버튼 |
| 시점 | 빈 곳을 옆으로 끌기 · [ ] 키 (2장부터) | 빈 곳을 옆으로 끌기 |
| 밀기 | 블록에 부딪히기 | 블록을 미는 방향으로 쓸기 |
| 거울 | 부딪히기 | 거울 터치 (걸어가서 돌림) |
| 기타 | Z 되돌리기 · R 다시 · H 힌트 · F 전체 화면 · Esc 메뉴 | 화면 위 버튼 |

## 착시 규칙 (2장부터)
- 카메라는 정확한 아이소메트릭이고 90° 단위로 돌릴 수 있어요(시점 0~3). 화면 쪽 방향 V=(±1,1,±1).
- **보이는 대로 이어져요:** 두 칸의 경계가 화면에서 정확히 겹치면(실제로는 V 의 정수배만큼 떨어져 있어도) 건널 수 있어요. 단, 두 칸 모두 화면에서 가장 앞에 보여야 해요(가려진 칸으로는 못 감). 실제로 붙은 칸이 있으면 그쪽이 먼저예요.
- 건너는 순간 인형은 k·V 만큼 순간 이동하지만, 화면에서는 보이지 않아요. 블록도 같은 규칙으로 밀려 가요(위로도, 아래로도).
- **기둥 뒤 숨은 길:** 스테이지에 정한 시점에서 기둥에 가려진 칸 하나를 건너뛰어 이어져요(한쪽으로만인 길도 있어요).
- **펜로즈 계단:** 계단으로 N층을 오른 끝이, 고리가 닫히는 시점에서는 처음 칸과 맞닿아요 — 뒤로 걸으면 꼭대기, 꼭대기에서 밀면 바닥.
- **손잡이 규칙:** 접힘선이 붙은 종이 위에 서 있어야 그 접힘선을 접을 수 있어요(흐린 접힘선은 지금 못 접는 것).
- 빛은 착시를 따르지 않아요. 실제 공간을 곧게 나아가요.
- 착시 장에서는 그림자가 실제 깊이를 드러내므로 그림자를 끄고, 빛은 카메라와 함께 돌아요.

## 구조 (논리 / 화면 / 충돌 분리)
```
js/logic/      ← Three.js 를 모르는 순수 논리 (Node 에서 테스트)
  math.js         90° 정수 회전 행렬, 시점 벡터·화면 키
  StageLoader.js  스테이지 JSON 검증·파싱 (시점·숨은 길·장식·손잡이 규칙·저장된 풀이 포함)
  Layout.js       접힘 각도 → 면 변환, 걸을 칸·벽 (캐시)
  Collision.js    이웃 판정: 실제 이웃 → 착시(화면 맞닿음) → 숨은 길, 블록 착시 밀기, 길찾기
  Connection.js   실제 연결 + 지금 시점의 착시 연결 목록 (화면 표시용)
  Puzzle.js · Fold.js · Sim.js
  Solver.js       너비 우선 자동 풀이 (시점 회전 포함) + 저장된 풀이로 다음 행동 찾기
js/render/     Renderer(회전하는 아이소 카메라·장별 그림자), StageView(착시 경계 빛·장식), …
js/core/       Game(시점 끌기·맞춤, 큰 무대 따라가기), Player(착시 칸 넘을 때 k·V 이동, 숨은 길 사라짐 연출), …
stages/        ch1 접기(튜토리얼) · ch2 시점 · ch3 가림 · ch4 불가능한 건축
tools/         스테이지 설계 스크립트 (ch2~4.mjs, lib.mjs: via·penrose·hiddenPair·veil·findLinks·district),
               explore.mjs(시점별 연결 + 풀이), trace.mjs, solutions.mjs, build.sh
```

## 스테이지 (4장 24개, 모두 자동 풀이로 해결 가능 + 실제 게임 조작으로 끝까지 재생 검증)
| 장 | 스테이지 (최소 행동 수) |
|---|---|
| 1 접기 (백지, 회전 잠금) | 첫 접기 1 · 건너기 3 · 스위치 3 · 닫힌 공간 3 · 반사 3 · 겹 2 |
| 2 시점 (살구) | 어긋난 다리 2 · 접힌 시선 2 · 끊어진 계단 3 · 가려진 길 4 · 무게의 시선 8 · 세 개의 시선 9 |
| 3 가림 (박하) | 기둥 뒤 2 · 끝없는 계단 1 · 두 개의 기둥 4 · 거꾸로 떨어지는 블록 6 · 기둥의 고리 6 · 가림의 탑 5 |
| 4 불가능한 건축 (라벤더) | 빛은 곧다 6 · 두 개의 고리 4 · 위로 떨어지는 블록 4 · 빛과 무게 8 · 두 개의 무게 16 · 불가능한 건축 14 |

행동 수는 접기·시점·밀기·거울만 센 값이에요(걷기 제외). 2~4장 스테이지는 `tools/ch2~4.mjs` 로 만들고,
`tools/build.sh` 가 생성 → 풀이 저장(`solution`, 힌트용) → 검증까지 해요. 설계 과정에서 생기는 우연한 착시 연결은
`tools/explore.mjs` 로 시점별로 확인하고, 매개변수 탐색으로 의도하지 않은 연결이 없는 배치를 골랐어요.

## 설정 · 저장
- 설정: 전체/음악/효과음 볼륨, 그래픽 품질(낮음: 그림자 끔·0.75배 해상도·Lambert / 보통: 1024 그림자 / 높음: 2048 부드러운 그림자·2배 해상도·종이 요철), 전체 화면. 바꾸면 바로 저장.
- 진행: 완료한 스테이지·최소 접기 기록, 일시정지 메뉴의 "저장"으로 스테이지 중간 상태 저장 → 메인 메뉴 "이어하기".
- localStorage (쓰기 전 백업 칸 유지, 손상 시 백업 사용, 버전 필드). 구글 로그인하면 Firestore `fold_users/{uid}` 에도 저장 — 게스트 진행은 첫 로그인 때 계정으로 옮기고, 로그아웃하면 게스트로.
- 관리자(사이트 주인 계정, 이메일 SHA-256 으로 판별): 모든 스테이지 열림 + 디버그 화면(` 키 / 일시정지 메뉴).

## 성능
- 접힘 배치 계산 캐시, 지오메트리·텍스처 공유, 연결 빛은 인스턴싱, 그림자 카메라를 무대에 맞춤.
- 가리는 면 반투명 처리는 4프레임마다. 힌트 탐색은 프레임을 12ms 씩 끊어 실행 (최대 4초, 넘으면 글 힌트).

## 테스트 결과
- `node tests/run.js`: 단위 테스트(회전·접기·연결·충돌·되돌리기) + 12개 스테이지 자동 풀이 → 실제 동작으로 재생해 출구 도착까지 통과.
- 브라우저(Chromium, Playwright): 12개 스테이지 모두 실제 게임 조작(걷기·계단·접기·밀기·거울·열쇠)으로 완료 확인, 모바일(iPhone 13 에뮬레이션) 터치 탭·접힘선 선택·화살표 접기·터치 드래그 접기·힌트 확인, 일시정지·저장·이어하기·품질 변경 확인. 콘솔 오류 없음.

## 아직 없는 것
- 벽(세로 면)·장식이 칸을 가리는 것까지 따지는 착시 판정 (지금은 걸을 수 있는 바닥끼리만 앞뒤를 따짐)
- 모뉴먼트 밸리식 손잡이로 돌리는 회전 구조물
- 스테이지 에디터 (데이터 구조는 에디터용으로 설계, JSON 직접 편집)
- 3~6장 콘텐츠 (구조는 지원, 지금은 2장 12스테이지) · 반투명 종이 재질
- 움직이는/회전하는 플랫폼 (조건부로 나타나는 다리만 있음)
- 접히는 도중 종이끼리 스치는 충돌 검사 (최종 배치만 검사), 접기 중 종이 휘어짐 표현 (강체 회전)
- 블록 쌓기, 접힌 종이에 플레이어 태워 옮기기
- IndexedDB 저장 (localStorage 만), 이어하기 후 되돌리기 기록 유지
