# Track Master (구 F1 Champion)

https://09jun4.github.io/track-master/ (서킷 레이스: circuit/, 드리프트 레이스: drift/, 랠리 레이스: rally/)

## 온라인 기능 (구글 로그인 · 계정 저장 · 랭킹)

Firebase(Auth + Firestore)를 씁니다. `js/firebase-config.js`가 비어 있으면 온라인 기능 없이 브라우저 저장만 사용해요.

1. https://console.firebase.google.com 에서 프로젝트 만들기 (애널리틱스는 꺼도 됨)
2. **Authentication** → 시작하기 → 로그인 방법 → **Google** 사용 설정
3. **Authentication** → 설정 → 승인된 도메인에 `09jun4.github.io` 추가
4. **Firestore Database** → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → 프로덕션 모드
5. **Firestore** → 규칙 탭에 `firestore.rules` 내용을 붙여 넣고 게시
6. 프로젝트 설정 → 내 앱 → 웹 앱(`</>`) 추가 → 표시되는 `firebaseConfig`의 `apiKey`, `authDomain`, `projectId`, `appId`를 `js/firebase-config.js`에 입력

## 서킷 레이스 그래픽 프리셋 (circuit/)

설정(메뉴의 **그래픽** 패널, 일시정지 화면)에서 **낮음 / 높음**을 고를 수 있어요. 기본값은 낮음이고, 선택은 이 브라우저(localStorage)와 저장 데이터(`gfx`, 로그인 시 계정 저장에도 같이)에 기억돼요.

| 프리셋 | 렌더러 | 내용 |
|---|---|---|
| 낮음 | `js/renderer.js` (Canvas 2D) | 기존 화면 그대로(원본 코드와 픽셀 단위 동일). 추가 다운로드 없음 |
| 높음 | `js/gfx/hi-*.js` (three.js r128, WebGL2 · WebGL1) | 3D 서킷·관람석·차량, 그림자·조명, 블룸·모션 블러·파티클 |

- 높음을 처음 고를 때만 `../js/vendor/three.min.js`(r128, 로컬)와 `js/gfx/hi-*.js`를 지연 로딩해요. 낮음 사용자의 로딩은 그대로예요.
- 모든 기기에서 높음을 고를 수 있어요. WebGL2가 없으면 WebGL1로, 둘 다 없으면 "이 기기는 3D 그래픽을 지원하지 않아요" 안내 후 낮음을 유지해요.
- 고사양 PC는 "높음 권장" 표시만 하고 자동으로 바꾸지 않아요. 저사양 기기는 높음을 켤 때 "느릴 수 있어요"를 한 번 알려요.
- 높음의 **세부 품질** 5단계(최고·높음·중간·낮춤·최소: 해상도 스케일, 그림자맵 크기·캐스케이드, MSAA, 블룸·모션 블러 탭 수, 관중·나무·파티클 양)는 설정에서 직접 고르고 브라우저에 저장돼요. **자동으로 낮추지 않아요.** 처음 값은 PC 높음(고사양 PC 최고), 모바일 중간이에요. 모바일은 발열 때문에 devicePixelRatio 상한 1.25.
- 차량은 cars.js의 색·비율을 그대로 쓰되, 실제 포뮬러처럼 매끈한 곡면(모노코크·노즈·사이드포드·엔진 커버는 둥근 단면을 이어 만든 형상, 앞뒤 날개는 에어포일 단면)으로 만들고, 표면은 카본 섬유(2x2 트윌 직조, 클리어코트)에 윗면만 리버리 도색이에요. 1인칭도 3D 둥근 콕피트(어깨·패드 림·헤일로·미러 하우징)로 그리고, 핸들과 미러 유리만 cockpit.js가 그려요.
- 1인칭 헤일로는 실제 FIA 헤일로처럼 3점 고정(머리 뒤 양옆 + 앞쪽 섀시)이에요. 타원 단면 고리와 앞 지지대가 한 몸체로 이어지고(지지대는 고리 굵기에서 시작해 약 50 mm 튜브로 가늘어짐), 고정점마다 볼트 체결부가 있어요. 3인칭 차량도 같은 형상이에요.
- 콕핏·차량 디테일은 세부 품질에 따라 달라요: 최고 = 전부 + 미러 속 화면 3D(뒤쪽 장면을 실시간으로 그림), 높음 = 안쪽 패딩, 카본 이음선, 퀵 패스너 볼트, 스위치 패널, 비상 스티커, 운전자 어깨·HANS·벨트·헤드레스트, 중간 = 패딩·벨트 단순화, 낮춤·최소 = 기본 둥근 콕핏.
- 차량 선택창: 높음이면 내 차 카드는 3D 차량이 천천히 돌고(드래그로 돌려보기), 상점·레이스 결과 포디움 카드는 같은 3D 모델의 스튜디오 이미지예요. 낮음은 기존 그림 그대로예요.
- 충돌 폭발: 주황 불덩이와 검은 연기 기둥, 불꽃, 카본 파편(트랙에 남음), 날개와 바퀴 2개가 떨어져 나가고 차체는 그을려요. 재시작하면 원래대로 돌아와요.
- 고속 속도감은 흔들림 없이: 차는 선명하게 두고 주변만 방사형 블러, 속도선, 가속/제동 때 천천히 움직이는 카메라 스프링, 넓어지는 화각, 리어 윙 끝 와류 자국.
- 레이스 중에 바꾸면 렌더러를 dispose 후 새로 만들어요. 탭이 백그라운드면 그리지 않고, WebGL 컨텍스트가 끊기면 낮음으로 돌아가요.
- 물리·카메라·랩 기록은 공유하고 높음 렌더러는 읽기만 해서, 같은 입력이면 랩 타임이 같아요.
- 주소에 `?gfx=high`(또는 `low`)를 붙이면 그 프리셋으로, `&gfxq=0~4`를 붙이면 세부 품질을 정해서 열려요(테스트용, 저장 안 함). `&gl=1`은 WebGL1 강제.

## 서킷 레이스 리얼리스틱 모드 (circuit/)

메뉴의 **리얼리스틱** 탭. 연습·AI 대전은 그대로 두고(같은 입력이면 원래 코드와 결과가 비트 단위로 같아요), 실제 F1과 비슷한 레이스 주말을 따로 진행해요. 입장 조건은 AI 대전과 같아요(F1 보유 + F1 5랩).

- **주말**: 예선 Q1(20명, 하위 5명 탈락) → Q2(15명) → Q3(10명), 세션마다 플라잉 랩 1회(트랙 리밋이면 랩 삭제). 예선은 설정에서 건너뛸 수 있어요(시뮬레이션 그리드). 결선 전에 출발 타이어를 골라요.
- **레이스 길이**: 실제 랩 수의 10 / 25 / 50 / 100%(몬자 53, 스즈카 53, 라스베이거스 50, 스파 44, 실버스톤 52, 인테를라고스 71). 타이어 수명은 짧은 레이스일수록 비례해서 줄어 전략이 살아 있어요.
- **그리드**: 가상의 10팀 20대(내 팀 + AI 팀메이트). AI 수준 4단계(이상적인 랩 대비 +7 / +4 / +2 / +0.5%), 팀 성능·드라이버 실력·레이스 당일 컨디션·작은 실수.
- **차량 물리(이 모드만)**: 2026 규정 F1 수치. 768 kg + 연료, ICE ~400 kW + MGU-K 190 kW(지속) / 350 kW(부스트, 4 MJ 배터리, 290→345 km/h에서 감소), 다운포스(접지력 = 타이어 마찰 × (1 + 다운포스/무게)), 최대 5.9 G 제동, 저속 휠스핀 한계, 액티브 에어로 **스트레이트 모드**(긴 직선에서 자동, 비 오면 꺼짐).
- **오버테이크 모드(MOM, DRS 대신)**: 감지선(결승선 300 m 전)에서 앞차와 1초 이내면 다음 랩에 사용 가능(**Shift** 키): 350 kW를 337 km/h까지 유지 + 0.5 MJ. 1랩과 세이프티카 재개 직후엔 꺼져요. B 키는 부스트(누르는 동안 배터리 사용).
- **타이어·연료·날씨**: 소프트/미디엄/하드 + 인터미디엇/풀 웨트, 마모(끝에 가면 급격히 떨어지는 클리프), 온도(새 타이어는 차가움), 연료 무게(랩마다 가벼워짐). 날씨 자동(서킷별 실제 비 확률)·맑음·변덕·비. 노면이 젖고 마르는 정도에 따라 타이어별 접지력이 바뀌어요.
- **팀 라디오**: 엔지니어가 피트 창·날씨·세이프티카 때 "BOX, BOX, BOX"를 부르면(브라우저 음성 합성으로 영어 음성도) 그 랩 끝에 들어가요. **F** 키로 확인, **X** 키로 "스테이 아웃"(안 들어가고 계속 주행). 직접 들어가고 싶으면 **F**(P도 됨), 다시 누르면 스테이 아웃.
- **피트스톱**: T 키로 다음 타이어. 피트 입구까지 남은 거리를 HUD에 표시하고, 입구에는 노란 PIT 표지판·트랙 가장자리 노란 선·바닥의 PIT IN / PIT OUT / 80 표시가 있어요. 피트월은 입구·출구에서 열려 있어요. 피트 입구(결승선 380 m 전)부터 자동으로 80 km/h 리미터 주행 → 팀 박스 정지(약 2.2~2.6초, 가끔 느린 스톱) → 출구(260 m 뒤). 높음 그래픽은 차고·머리 위 갠트리(조명·릴리스 신호등)·피트월과 크루 17명(팀 색 2톤 슈트, 바이저 헬멧, 무릎 꿇은 휠건, 앞뒤 잭, 타이어 운반)의 3D 시네마틱. 크루는 박스 위치에 고정되어 피트 아웃 때 차를 따라가지 않아요, 낮음은 2D 피트스톱 패널.
- **비·타이어 온도·슬립스트림**: 비가 오면 슬릭 그립이 크게 줄고(젖은 노면 약 1/3) 코너에서 미끄러져요(조향이 그립 한계를 넘을 수 있음). 타이어 온도는 주행·코너·제동·미끄러짐으로 오르고 공기와 비에 식으며, 컴파운드별 적정 온도(소프트 100°C, 미디엄 106, 하드 113, 인터 72, 웨트 58)에서 멀어질수록 그립이 줄고 과열되면 마모가 빨라져요. HUD에 네 바퀴 온도를 색으로 보여줘요. 앞차 55 m 안 바로 뒤에서는 슬립스트림(TOW: 공기저항 감소, 코너 다운포스는 감소).
- **런오프·그래블·소시지 연석(모든 모드)**: 코너 바깥 런오프를 실제 서킷처럼 넓혔어요(코너마다 기본 6 m + 900/반지름, 최대 24 m, 다른 구간과 겹치지 않게 자동 제한). 넓은 곳은 흰 선에서 4.5 m 뒤부터 그래블(크게 감속, 진동)이고, 급한 코너 절반은 출구 바깥 연석 뒤에 높이 10 cm 노란 소시지 연석(밟으면 크게 튀고 감속). 트랙 리밋 페널티는 받아도 벽 충돌은 줄어요.
- **파손(리얼리스틱)**: 폭발 기준 아래 충돌은 부위·세기에 따라 프런트윙 휨→파손(매달림)→이탈, 앞·뒤 서스펜션 파손(바퀴가 안쪽으로 기울고 그쪽으로 쏠림), 리어윙 손상·이탈, 소시지 연석 고속 통과 시 플로어 손상. 다운포스·그립·최고속도가 떨어지고, 팀이 BOX를 부르며 위험한 차는 흑색·주황 깃발(2랩 무시 시 드라이브스루→20초). 앞차를 들이받으면 충돌 유발 5초(상대 리타이어 시 10초). 피트에서 노즈 교체 +8.5초, 리어윙 +10초, 서스펜션 +25초. 파편 수는 그래픽 품질 단계에 맞춰요.
- **모바일 조작**: 메뉴의 '조작'에서 버튼/기울기(자이로) 조향, 감도 3단계, 중앙 보정, 방향 반전, 진동(끄기/약/중/강: 충돌·파손·소시지 연석, 주행 중 엔진 회전수에 따라 빨라지고 세지는 펄스와 변속 때 짧은 킥, 모든 모드; 안드로이드만, 아이폰 사파리는 진동 API 없음) 설정. 가속·브레이크 버튼은 F1 페달 모양(문구 포함).
- **연석(모든 모드)**: 실제 F1 연석처럼 폭 1.5 m, 안쪽 0.3 m 경사로 4 cm까지 올라오는 둥근 턱에 0.6 m 간격 요철(±1.2 cm). 바퀴가 올라가면 차체가 기울고 떨리며(높음), 카메라도 요철에 맞춰 흔들려요(낮음·높음, 1인칭 포함). 연습·AI 대전에서는 보이는 효과만(랩 타임 그대로), 리얼리스틱에서는 연석 위 그립 감소(비 오면 더 큼)와 차체 흔들림도 있어요. 공용 코드는 `js/kerb.js`.
- **스타트**: 신호가 1초 간격(실제와 같음)으로 켜지고, 1번째 신호 동안 그리드 전체를 훑고, 2번째는 내 차 정면→측면, 3번째는 반대쪽(뒤→반대 측면), 4번째부터 내 시점으로 돌아와요.
- **규칙**: 세이프티카(차량 대열, 추월 금지, "이번 랩 피트인" 후 리더가 재출발)·버추얼 세이프티카(델타 유지), 옐로·블루·흑백·체커기, 트랙 리밋 경고 3회 후 5초 페널티(다음 피트스톱에서 소화, 아니면 기록에 더함), 세이프티카 중 추월·VSC 델타 위반 5초. AI도 사고·고장 리타이어, 페널티, 전략(0~2스톱), 세이프티카 때 값싼 피트스톱, 비에 따라 타이어 교체.
- **시즌**: 6라운드(스즈카 → 실버스톤 → 스파 → 몬자 → 인테를라고스 → 라스베이거스), 실제 포인트(25-18-15-12-10-8-6-4-2-1), 드라이버·컨스트럭터 순위, 상금. 저장 데이터의 `real` 필드(설정·시즌·지난 시즌)에 들어가 로그인하면 계정에도 같이 저장돼요(Firestore 규칙 변경 없음).
