✦ Random generator — x = beats, 4 bars
Syntax reference
  • x is time, the result y is frequency in Hz.
  • Any other letter (a, b, amp…) becomes a slider.
  • Operators: + - * / ^, implicit 2x
  • Functions: sin cos tan sqrt abs exp log log2 log10
  • Steps & rhythm: floor ceil round mod(x,n) sign
  • Piecewise: {x<2: 220, x<4: 330, 440}
    no default → silent: {mod(x,1)<0.5: 440}
  • Ranges: {1<x<3: 300}
  • midi(n) MIDI note → Hz (60 = C4, 69 = A4)
  • noise(x) smooth random −1…1, rand(x) stepped random 0…1
  • saw(x) tri(x) sqw(x) periodic shapes (period 1, −1…1)
  • clamp(v, lo, hi), constants pi e
  • pick(i, a, b, c…) step through a list (index floored, wraps)
  • gate(p, duty) 1 during the first duty of each unit, else silent — e.g. 440*gate(4x, 0.5)
  • euclid(i, k, n) 1 on Euclidean rhythm hits (k of n steps)
  • Scales (degree → semitones): minor phry harm dor pent major, e.g. midi(57 + minor(floor(x)))
  • Below 20 Hz, above 8000 Hz, or undefined → silence.
  • Click the graph to jump the playhead. Space = play/pause.
